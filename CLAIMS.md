# Claims Boundary

## Allowed

- OSIT is used here as an operational model for state-aware information workflows.
- `R`, `Phi_eff`, `H_eff` and MTS residue are testable metrics in this repository.
- Channel gates provide explicit `APPROVE`, `REVIEW` and `BLOCK` decisions for synthetic or documented inputs.

## Not Claimed

- This repository does not prove new physics.
- This repository does not prove consciousness.
- This repository does not claim AGI.
- This repository does not guarantee prediction, safety or truth.
- This repository does not replace Shannon information theory.

## Required Posture

Every new metric must include:

- input assumptions;
- expected output range;
- falsifier or negative test;
- claim downgrade rule when evidence is missing.
