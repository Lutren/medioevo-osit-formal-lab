# Claims Boundary

## Allowed

- OSIT is used here as an operational model for state-aware information workflows.
- `R`, `Phi_eff`, `H_eff` and MTS residue are testable metrics in this repository.
- Channel gates provide explicit `APPROVE`, `REVIEW` and `BLOCK` decisions for synthetic or documented inputs.
- The repository may publish schemas, validators, synthetic examples, falsifier templates and claim downgrade rules.
- Physics references may be used as background when cited, but OSIT metrics remain formal-lab constructs unless separately validated.

## Not Claimed

- This repository does not prove new physics.
- This repository does not prove consciousness.
- This repository does not claim AGI.
- This repository does not guarantee prediction, safety or truth.
- This repository does not replace Shannon information theory.
- This repository does not publish the private OSIT/MEDIOEVO canon, Wabi internals, proprietary calibration, books, LORE, RPG/TCG or video/audio source files.

## Required Posture

Every new metric must include:

- input assumptions;
- expected output range;
- falsifier or negative test;
- claim downgrade rule when evidence is missing.

## Claim Classifier

Use these labels in docs and examples:

| label | meaning |
|---|---|
| `ESTABLISHED_BACKGROUND` | cited external science or engineering background |
| `ENGINEERING_ANALOGY` | useful analogy for agent workflows |
| `FORMAL_LAB` | reproducible metric or toy model in this repo |
| `SYNTHETIC_DEMO` | example fixture, not real-world evidence |
| `BLOCKED_CLAIM` | unsupported strong claim that must not be published as proof |
